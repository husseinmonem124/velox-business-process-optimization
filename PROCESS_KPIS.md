# VELOX — Process KPI Framework

## 1. Purpose

Key Performance Indicators (KPIs) are used to measure the efficiency and quality of the VELOX order fulfillment process.

The KPIs will allow VELOX to compare the current AS-IS process with the proposed TO-BE process.

## 2. Key Process KPIs

| KPI                         | Definition                                                     | Current Target |
| --------------------------- | -------------------------------------------------------------- | -------------: |
| Total Order Processing Time | Time from order placement to shipment                          |       12 hours |
| Payment Verification Time   | Time required to confirm payment                               |      2.5 hours |

| Cost per Order              | Average operational cost required to process one order         |          €8.50 |

## 3. KPI Definitions

### Total Order Processing Time

Measures the total time between the customer placing an order and the order being shipped.

**Goal:** Reduce the average processing time.

### Inventory Error Rate

Measures the percentage of orders where the recorded inventory does not match the actual available stock.

**Goal:** Reduce inventory discrepancies.

### First-Time-Right Rate

Measures the percentage of orders that move through the process without requiring correction, rework, or manual intervention caused by an error.

**Goal:** Increase process accuracy.

### Manual Processing Rate

Measures how much of the order fulfillment process still requires employees to perform tasks manually.

**Goal:** Reduce unnecessary manual work through automation.

### Order Delay Rate

Measures the percentage of orders that take longer than the expected processing time.

**Goal:** Reduce delayed orders.

### Cost per Order

Measures the average operational cost associated with processing one customer order.

**Goal:** Reduce the cost of fulfilling each order while maintaining service quality.

## 4. KPI Improvement Objectives

The future TO-BE process should aim to achieve:

* Faster order processing.
* Fewer inventory errors.
* Less manual work.
* Higher first-time-right performance.
* Fewer delayed orders.
* Lower processing costs.

These KPIs will be used later to measure the expected impact of the proposed process improvements.
