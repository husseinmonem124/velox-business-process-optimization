# VELOX — AS-IS Order Fulfillment Process

## 1. Process Overview

VELOX is a fictional German online retailer selling consumer electronics.

The current order fulfillment process begins when a customer places an order and ends when the order is shipped.

The current process consists of six main stages:

1. Customer Order
2. Payment Verification
3. Inventory Check
4. Warehouse Picking
5. Packing
6. Shipping

The process currently relies on several manual activities, which can create delays, duplicate work, and inventory errors.

## 2. Current AS-IS Process

### Step 1 — Customer Order

The customer places an order through the VELOX online store.

The order information is recorded in the company's order system.

The order is then sent to the operations team for processing.

### Step 2 — Payment Verification

An employee manually checks whether the customer's payment has been successfully received.

If the payment requires additional verification, the order is temporarily placed on hold.

Once payment is confirmed, the employee marks the order as ready for the next stage.

### Step 3 — Inventory Check

An employee checks the availability of the ordered products.

The employee may need to consult the inventory system manually.

If a product is unavailable, the order may be delayed while the employee contacts another department or checks alternative inventory.

### Step 4 — Warehouse Picking

The warehouse receives the order information.

A warehouse employee searches for the required products and collects them.

Employees may occasionally discover that the recorded inventory does not match the actual stock in the warehouse.

This can result in additional delays.

### Step 5 — Packing

The picked products are transferred to the packing area.

A warehouse employee verifies the order and prepares the package.

The shipping information is then entered or checked before the package is prepared for dispatch.

### Step 6 — Shipping

The completed package is handed to the shipping provider.

The tracking information is recorded in the order system.

The customer receives a shipping notification.

## 3. Current Process Problems

The current process has several potential inefficiencies:

* Manual payment verification can create delays.
* Inventory checks require employee involvement.
* The same order information may be entered multiple times.
* Inventory discrepancies can interrupt warehouse picking.
* Orders can wait between process stages.
* Employees rely on manual communication between departments.
* Managers have limited visibility into process bottlenecks.
* Delays can increase operational costs and reduce customer satisfaction.

## 4. Business Objective

The objective of the process optimization project is to identify the major bottlenecks in the current order fulfillment process and design an improved TO-BE process.

The improved process should aim to:

* Reduce order processing time.
* Reduce manual work.
* Reduce inventory errors.
* Improve communication between departments.
* Increase warehouse efficiency.
* Reduce operational costs.
* Improve customer satisfaction.

## 5. Process Optimization Goal

**Current state:** Manual and fragmented order fulfillment process.

**Target state:** Faster, more automated, transparent, and reliable order fulfillment process.
